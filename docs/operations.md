# Запуск и эксплуатация

## Требования

Для локального запуска нужны Python 3.12 или новее, Node.js 22.12 или новее, npm и доступ к Keitaro Admin API. Node.js нужен для dev-сервера и сборки. SQLite работает через Python и создаёт локальный файл БД.

Запуск по умолчанию:

| Сервис | Адрес |
|---|---|
| Интерфейс | [127.0.0.1:5173](http://127.0.0.1:5173/) |
| FastAPI | [127.0.0.1:8000](http://127.0.0.1:8000/) |
| Swagger приложения | [127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) |
| Проверка БД | [127.0.0.1:8000/api/v1/health](http://127.0.0.1:8000/api/v1/health) |

## Окружение бэкенда

Из каталога `backend/` скопируйте `.env.example` в `.env` и заполните параметры подключения. Файл читает FastAPI через Pydantic Settings. Переменные процесса имеют приоритет над `.env`. После изменения `.env` перезапустите бэкенд.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `KEITARO_BASE_URL` | `https://keitaro-for-tests.etolegko.com` | Адрес инстанса Keitaro. FastAPI добавляет путь `/admin_api/v1/` |
| `KEITARO_API_KEY` | Пусто | Ключ запросов к Admin API. Хранится в `backend/.env` или окружении процесса |
| `KEITARO_DOMAIN` | Пусто | Имя активного домена без схемы и пути. При пустом значении ключу должен быть доступен ровно один активный домен |
| `KEITARO_CAMPAIGN_GROUP` | `FORTESTS` | Имя группы кампаний в Keitaro |
| `KEITARO_TRAFFIC_SOURCE` | `FORTESTS` | Имя активного источника в Keitaro |
| `DATABASE_URL` | SQLite в `backend/data/app.sqlite3` | URL подключения SQLAlchemy. Для другого файла SQLite укажите существующий родительский каталог |

Адрес API настраивается на бэкенде. Браузер использует относительный путь `/api/v1`. Реальный `backend/.env` игнорируется Git, а `backend/.env.example` содержит пустое значение ключа.

Проверка `/health` выполняет запрос к БД и работает с пустым ключом. Для проверки чтения Keitaro используйте `GET /api/v1/campaigns?limit=1`. Создание кампании требует доступа к офферу, домену, группе, источнику и операциям записи кампаний и потоков. Для кликов за сегодня требуется доступ к отчётам.

## Подготовка и миграции

Windows PowerShell:

```powershell
cd backend
py -m venv .venv
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m alembic current
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Linux и macOS:

```sh
cd backend
python3 -m venv .venv
test -f .env || cp .env.example .env
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m alembic upgrade head
.venv/bin/python -m alembic current
.venv/bin/python -m uvicorn app.main:app --reload
```

`alembic upgrade head` применяет все недостающие миграции. Выполняйте его после обновления кода перед запуском сервера. Команда `alembic current` показывает текущую ревизию. На текущей схеме ожидается `0002 (head)`. Команда `alembic check` сравнивает БД с моделями SQLAlchemy.

| Ревизия | Изменение |
|---|---|
| `0001` | Начальная точка истории миграций |
| `0002` | Таблица `campaign_editor_state` для черновиков, удалённых офферов и закреплённых долей |

Перед экспериментами с миграциями сохраните копию файла рабочей SQLite при остановленном приложении. Откат `0002` удаляет таблицу редактора и её содержимое.

## Фронтенд и прокси

Во втором терминале из корня репозитория выполните:

```sh
cd frontend
npm ci
npm run dev
```

В PowerShell можно вызывать `npm.cmd`, если политика запуска скриптов блокирует `npm.ps1`. `npm ci` устанавливает версии из `package-lock.json`. `npm run build` выполняет проверку TypeScript и собирает статические файлы в `frontend/dist/`.

Vite отправляет HTTP и WebSocket по префиксу `/api` в FastAPI. Если статическую сборку раздаёт другой сервер, ему нужны прокси для `/api` с поддержкой WebSocket Upgrade и отдача `index.html` для путей редактора `/campaigns/{id}`. Прокси передаёт исходный `Host`, чтобы WebSocket мог сверить его с `Origin` браузера.

Локальный проект рассчитан на один процесс FastAPI. Так блокировка операций и цикл опроса общие для всех вкладок, обслуживающихся этим процессом. Схема запуска из README привязывает сервисы к loopback.

## Диагностика

| Симптом | Что проверить |
|---|---|
| Интерфейс не загружает список | Запустите FastAPI, проверьте `/health` и прямой ответ `GET /api/v1/campaigns?limit=1` |
| `503` при обращении к кампаниям | Проверьте наличие ключа. Если ошибка возникает при создании, проверьте домен, группу и источник из `backend/.env` |
| Keitaro отказал в доступе | Проверьте ключ и права на нужную операцию. В ответе приложения может быть код `upstream_status` |
| `no such table: campaign_editor_state` | Примените `alembic upgrade head` с тем же `DATABASE_URL`, который использует FastAPI |
| Изменения в Keitaro видны только после ручного обновления | Проверьте WebSocket в браузере и проксирование `/api` с Upgrade. В локальном запуске это настроено в `frontend/vite.config.ts` |
| Клики показываются как «нет данных» | На учебном стенде отчёты недоступны. На других инстансах проверьте доступ ключа к `POST /admin_api/v1/report/build` |
| Публикация вернула `409` | Перечитайте редактор. Если изменился Keitaro, проверьте актуальное состояние и подтвердите требуемую перезапись |
| Публикация прервалась на одном потоке | Перечитайте редактор перед повторной попыткой. Подтверждённые потоки уже сохранены, продолжение доступно для оставшихся |
